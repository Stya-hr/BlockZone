# 小队状态 HUD

仅在 Battlezone 对局中显示，锚定屏幕左下角。自己位于最下方，队友位于上方；按 2560×1440 参考画布的统一比例缩放，超宽屏使用左下锚点；不按 Minecraft GUI 缩放选项单独放大组件。退出地图、对局重置、FPSMatch 客户端重置和断线时清除状态。

## 组件职责

- `SquadHud`：通过 FPSMatch `FPSMGameHudManager` / `IHudRenderer` 注册 Battlezone HUD；控制界面、F1 和旁观显示。
- `SquadStatusPanel`：屏幕锚点、缩放、成员排序和子组件组合。
- `TeammateStatusRow` / `LocalPlayerStatus`：队友紧凑行和自己的较大状态区。
- `PlayerAvatar`：玩家皮肤头像、参考图状态边框、离线和淘汰遮罩；无皮肤缓存时使用 Minecraft 默认皮肤。
- `PlayerIdentity`：成员编号和截断的名字。
- `PlayerVitals`：按在线、淘汰、倒地和正常状态切换子组件。
- `HealthBar`：按真实最大生命值归一化；白色生命填充和绿色 2px 底线。
- `ArmorSegments`：按现有 `PlateCapacity` 和地图单板护甲值绘制 0–3 段，支持部分护甲。
- `DownedProgress`：失血倒计时；有救援进度时切换为救援进度条。
- `PlayerActionHints`：复用当前背包绑定；主手持有护甲板时显示实际使用物品绑定及护甲板图标，不新增操作绑定。
- `SquadHudGraphics` / `SquadHudStyle`：Modern UI 文字引擎、1px 名字描边和统一设计值；不创建交互屏幕或抢占输入。

## 数据边界

FPSMatch `ServerTeam` / `PlayerData` 是队伍、身份和淘汰状态的来源。`SquadStateSync` 从当前队伍构建只读 `SquadMemberStatus`，补充服务器生命、吸收护甲、护甲容量和本模组 `CombatStateSync` 的倒地／救援数据。

每 5 tick 检查一次，快照变化才发送，且仅发送给该队在线成员。敌队和独立旁观队伍不会获得这些状态。离线队友仍在名单中，以离线文字显示，不依赖客户端实体追踪距离。

`SquadMemberNumbers` 在成员仍属于队伍时保持编号与颜色；离队释放编号。`SquadClientState` 只在 FPSMatch 当前游戏类型、地图和队伍与快照一致时提供数据，避免跨地图残留。新增包改变网络协议版本为 27，客户端与服务端需要一起更新。

原个人血甲 HUD 的渲染已由小队面板替代；原版血量、护甲和饥饿条只在新 HUD 有有效数据且 FPSMatch HUD 启用时隐藏。现有屏幕中央救援提示继续保留。

## SVG 样式基准

用户提供的 `HUD/Screen/Viewport=QHD.svg` 是样式基准，原画布为 2560×1440。尺寸均以设计像素记录，整组使用 `min(framebufferWidth/2560, framebufferHeight/1440) / guiScale`（避免 GUI 尺寸取整误差） 统一缩放，保持头像、文字、状态条和间距之间的比例。

| 元素 | QHD 坐标／尺寸 |
| --- | --- |
| 自己头像 | (82, 1256)，64×64，内边距 4 |
| 最近队友头像 | (82, 1214)，32×32，内边距 4 |
| 队友纵向步长 | 53 |
| 自己编号 | (157, 1263.5)，18×18 |
| 自己名字 | (191, 1264.5)，字号 20，浅色字／绿色 1px 描边 |
| 自己护甲 | (157, 1288)，总宽 360，高 12，段间距 8，底线 2 |
| 自己生命 | (157, 1304)，宽 360，高 16，底线 2 |
| 队友护甲 | (125, 1230)，总宽 151，高 7，段间距 8，底线 2 |

## 验证

- `./gradlew test build`：134 项单元测试通过，模组与资源包构建通过。
- `./gradlew runGameTestServer`：46 项 GameTest 通过；新增测试覆盖同队隔离、离线成员保留、网络往返和对局重置。
- Minecraft MCP 实机：进入对局显示、真实头像、护甲容量与部分护甲、白底绑定提示、离队后清理并恢复原版状态条。
- 按 2560×1440 启动时本机窗口被桌面限制到 1920×1026；已在该实际画面尺寸核对统一缩放，未声称完成原生 QHD 像素截图比较。
- 断服时测试环境原有的 `MouseHandler.turnPlayer` 空玩家崩溃在早于本功能的测试记录中也存在；本次未修改鼠标或旁观接口。
