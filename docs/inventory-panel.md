# 背包静态面板

进入世界后按 **I** 打开，按 **I / Tab / Esc** 关闭；可以在控制设置中修改打开键。
此阶段只展示设计中的固定内容，丢弃、请求、装备和数量均未接入游戏逻辑。

布局以导出的 2560 × 1440 画框为基准，保持纵横比并锚定底部中央；整体放大 20%，底部留白为 122 个设计单位。
打开时隐藏原版 HUD，底板保持透明，游戏不会暂停。

## 素材

- `src/main/resources/assets/blockzone/gui/inventory/`：独立 SVG 源文件。
- 运行时解析 SVG，按实际屏幕尺寸生成 GPU 纹理缓存；不使用预导出的 PNG。
- 12 个图标：背包、护甲板、头盔、护甲、盾牌、加号、步枪、手雷、电池、医疗包、物品护甲板、弹药。
- `labels` 保留设计导出的描边文字和按键提示，供静态预览使用；接入逻辑时应替换为可本地化的动态文字。
- 全部图标均为纯 SVG 矢量路径，透明背景；步枪和破片手雷采用与其他图标一致的 `#F3F7F8` 剪影风格。
- 步枪和手雷为手绘素材，重新提取脚本会保留它们，不会用原始位图覆盖。
- 不包含设计中的世界截图和小地图。
- 底板：黑色、45% 透明度（55% 不透明度）；普通边框：`#666666`、45% 不透明度；选中边框：`#F3F7F8`、100% 不透明度。边框为 2 个设计单位，至少为 1.5 个物理屏幕像素。
- 所有槽位图标作为空槽物品占位背景，统一为 25% 不透明度；步枪使用 M4 风格轮廓。
- 槽位文字放大 25%，底部增加铺满槽位内部宽度的黑色底条（40% 不透明度，高 26 个设计单位）；底部按键提示放大 15%。

重新提取 SVG 素材：

```sh
python tools/export_inventory_assets.py /path/to/BlockZone.zip
```

## 验证

已通过 Gradle 编译与资源处理，并使用 `minecraft-mod-mcp` 连接现有测试服检查：
面板打开、Tab / Esc 关闭、SVG 运行时加载、透明图标、灰显状态、边框可见、
放大上移及原版快捷栏隐藏。另已验证 `jarJar` / `reobfJarJar` 分发包构建。
尚未接入任何物品操作；请验收外观后再合并功能分支。

SVG 渲染使用随模组打包的 JSVG。分发时使用 `build/libs/*-all.jar`，
其中包含 SVG 运行依赖；`assemble` 会生成并重混淆该包。
